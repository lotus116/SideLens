# SideLens V0.1 设计

## 目标与边界

验证第二视角能否改善人与 AI 协作中的下一步判断。Skill 是低成本起点；插件、Agent 或软件是可能的后续交付方式，不预设必须升级。

审视双方的共同假设，区分用户想得到的结果、明确约束、暂定方法与后续授权变更。允许大胆提出候选解释，但不能把猜测当作用户的真实动机。

## 工作流程

1. 在重复投入、反复不满或重要决策前，检查新证据是否支持下一步。正常探索获得新信息时不必干预。
2. 提供用户原话、目标变更、实际结果和原始材料位置；把主 Agent 的解释单独标注。
3. 使用一个新上下文的审视者，先独立判断最值得解决的问题，再对照主线。允许有边界的补查，不递归委派。
4. 优先输出一项重要发现：依据、对决定的影响、最小验证，以及什么证据会削弱疑虑。
5. 主 Agent 说明采纳、暂缓或不采纳的理由，继续已授权工作。用户沉默不增加权限。

方案顺利推进但成功指标与需求不符，也可以提出简短、暂定的挑战。没有实质发现时，主动检查不制造打断；手动请求则简短说明判断。

## 主动调用约定

可按需加入适用项目的指令，不自动修改用户的全局配置：

> 当准备重复投入、用户再次表达同一不满，或即将作出显著限制后续选择的决定时，简短核对新获得的证据是否支持下一步。有具体疑点时使用 SideLens；正常探索获得新信息时继续。方案进展顺利但成功指标与需求不符，也可以提出简短挑战。已处理的问题没有新证据时不重复提醒。

自动调用依赖宿主与模型判断。新上下文只能降低被主线带偏的风险，不保证独立思考。审视者只读是行为约定，不构成独立权限隔离。
