# SideLens · 旁见

为人与 AI 的协作提供第二视角：发现遗漏、质疑共同前提，帮助判断下一步是否值得继续。

适合反复尝试却没有新进展、讨论绕圈，或想在重要决定前重新审视方向时使用。

## 安装到 Codex

把下面这句话发给 Codex：

```text
请安装 https://github.com/lotus116/SideLens 仓库中的 skills/sidelens 技能。
```

安装后，下一轮对话即可调用。

## 使用

直接输入：

```text
$sidelens 审视我们最近的讨论：目标有没有偏移？下一步最值得验证什么？
```

也可以针对一个决定：

```text
$sidelens 在继续这轮迭代之前，检查我们是否遗漏了关键证据或默认了错误前提。
```

SideLens 会给出简短、有依据的提醒和最小验证建议；没有值得干预的问题时，也会建议继续。支持子 Agent 的环境会使用独立审视，不支持时明确说明降级。

## 需要知道

- 支持手动调用，也允许 Codex 根据上下文主动调用；自动触发是尽力而为，不是后台监控。
- 默认提供审视建议，不自行修改业务代码或替你改变目标。
- 当前为早期原型，效果仍需真实任务验证。
